# macOS 环境依赖安装说明

## 系统工具（Homebrew）

```bash
# 安装 Homebrew（若尚未安装）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# OCR（轨迹线时间识别）
brew install tesseract

# ADB（日志打包 / 删除）
brew install android-platform-tools
```

## Python 依赖

```bash
cd Beatbot-tools
python3 -m venv .venv_run
source .venv_run/bin/activate
pip install -r requirements.txt
```

## 可选

- USB 转串口（CH340 / CP210x）：按芯片厂商安装 macOS 驱动
- 自定义输出目录：`export BEATBOT_DIST=~/Desktop/BeatbotDist`

## 不需要（相对 Windows）

- `VC_redist.x64.exe`
- Windows 版 Tesseract 安装包
- 将 `C:\Program Files\Tesseract-OCR` 加入 PATH
